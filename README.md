# Presente

Lista de perfumes que o Gabriel quer ganhar, com o gosto dele para acertar no presente.

- **Ver:** https://gabrielkopi.github.io/presente/
- **Editar:** https://gabrielkopi.github.io/presente/#editar (salva no aparelho; "Enviar link" gera o link para compartilhar).

Site estático, sem servidor. Catálogo de 501 perfumes gerado por `tools/build-presente.py` no projeto ELIXIR. Fotos de produto pertencem às marcas e lojas; notas publicadas pelas marcas e pela base Scento (CC BY 4.0). Fonte DM Sans sob OFL.
